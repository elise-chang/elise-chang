# Hi, I'm Elise!

I'm a senior at **UC Berkeley** double majoring in **Data Science and Cognitive Science**. My interests are robotics R&D, AI/ML, data analytics, and UI/UX.

My work spans React interfaces, data engineering pipelines, and interactive robotics.

- **Wildfire Data Engineering** — Python, Pandas, and SQL pipelines for cleaning and integrating over 200K text, image, and geospatial records. *
- **Educational Panda Robot** — An interactive robot integrating microcontrollers, sensors, servo control, and computer vision. *
- **[Miramonte FIRST Robotics (2022–2023)](https://github.com/elise-chang/Miramonte-FRC-Robotics-Portfolio)** — Java/WPILib robotics projects spanning drivetrain control, intake and shooter mechanisms, timed autonomous routines, and Limelight telemetry. - **[Job Posting Conversion Prediction](https://github.com/elise-chang/job-posting-conversion-prediction)** — A data science case study comparing machine-learning models on LinkedIn job-posting data using structured features and TF-IDF text.
